# MiniLang — интерпретируемый язык программирования на Rust

Учебный проект интерпретатора простого императивного языка программирования **MiniLang**, реализованный на языке Rust.

## Возможности языка
* **Типы данных:** числа с плавающей точкой (`Number`) и логические значения (`true`, `false`).
* **Арифметика:** `+`, `-`, `*`, `/`, `%`, унарный минус `-x` и группировка скобками `( ... )`.
* **Операции сравнения:** `==`, `!=`, `>`, `<`, `>=`, `<=`.
* **Переменные:** объявление (`let x = 10`) и изменение значения (`x = x + 1`).
* **Условное ветвление:** конструкции `if ... { ... } else { ... }` (блок `else` необязателен).
* **Циклы:** цикл с предусловием `while ... { ... }` со встроенной защитой от бесконечного зацикливания (лимит 10 000 итераций).
* **Вывод:** команда `print <выражение>`.

## Структура проекта
* `src/token.rs` — определение токенов языка.
* `src/lexer.rs` — лексический анализатор (разбиение исходного текста на токены).
* `src/ast.rs` — узлы абстрактного синтаксического дерева (`Expr`, `Stmt`) и типы значений (`Value`).
* `src/parser.rs` — синтаксический анализатор (рекурсивный спуск с учётом приоритета операций).
* `src/evaluator.rs` — интерпретатор (выполнение AST, таблица переменных, проверка типов).
* `src/main.rs` — точка входа, чтение файлов и обработка ошибок.
* `examples/` — примеры программ на языке MiniLang.

## Инструкция по запуску

### Требования
* Установленный инструментарий **Rust** и менеджер пакетов **Cargo** (`rustc`, `cargo`).

### Сборка и запуск
1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd minilang
   ```
2. Запустите любой из готовых примеров:
   ```bash
   cargo run -- examples/test_if.ml
   cargo run -- examples/test_while.ml
   cargo run -- examples/test_error.ml
   ```
